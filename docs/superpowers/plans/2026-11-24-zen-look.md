# studyrun Zen look: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** studyrun's frontend uses the family's Zen design (tokens, JetBrains Mono, frame, header bar, wallpaper, theme toggle) with peach as its accent.

**Architecture:** A ported `src/lib/theme/tokens.css` (from tidalwave) replaces `src/app.css`'s ad-hoc variables. The layout gains tidalwave's Zen frame and a `Header` with navigation and a `ThemeToggle` backed by a `theme` store. Every page and component then uses only the tokens.

**Tech Stack:** SvelteKit (adapter-static), Svelte 5, TypeScript, Vitest + Testing Library, `@fontsource-variable/jetbrains-mono`, Playwright (pre-installed Chromium) for screenshots.

**Spec:** `docs/superpowers/specs/2026-11-24-zen-design.md`

## Global Constraints

- Reference: `~/git/tidalwave/frontend/src/lib/theme/tokens.css`, `src/routes/+layout.svelte` (Zen frame), `src/lib/components/{Header,ThemeToggle}.svelte`, `src/lib/stores/theme.ts`. Read-only. Port these and trim them; don't re-derive them.
- Accent: Mocha `--accent: #fab387` (Catppuccin Mocha peach), Latte `--accent: #fe640b` (Catppuccin Latte peach). Latte peach is drawn for surfaces only: `--accent-text` (anything that is read, a fill carrying text, focus rings) must be the same hue darkened until it reaches ≥ 4.5:1 on crust, mantle and base. Compute and state the ratios in a comment, as tidalwave does for mauve. Mocha `--accent-text` is `--accent` if it reaches 4.5:1 (check). `--accent-soft` is the accent at the alpha tidalwave uses. The wallpaper moon uses the accent hex in both themes.
- `--success` and `--error` keep Catppuccin green and red (tidalwave's values) and mean correct and wrong. Nothing else uses them.
- Theme store: `type Theme = 'mocha' | 'latte'`, localStorage key `studyrun-theme`, default `mocha`, sets `document.documentElement.dataset.theme`.
- Radii 16 (cards), 10 (buttons and inputs), 8 (chips); no pills. No decorative borders. Shadow only on free-floating cards (`--glass-shadow`).
- Touch targets stay ≥ 44 px. Layout works at 360 px. German copy unchanged.
- Existing tests keep passing unchanged except where a test asserted a removed CSS class; roles, labels and texts must not change.
- Commits: Conventional Commits with scope `frontend`, signed, no attribution, messages through the humanizer skill (embedded). Run frontend commands as `nix --extra-experimental-features 'nix-command flakes' develop /home/paul/git/studyrun -c bash -c 'cd /home/paul/git/studyrun/frontend && <cmd>'`.

2. The header at 360 px: with four nav links plus the toggle it must not overflow horizontally. `--bar-h` must match the real height at the wrap breakpoint, or the frame's corners drift. Checked with the Task 2 screenshots.
3. Theme flash: the stored theme should apply before first paint. Put a tiny inline script in `app.html`, as tidalwave or linkhop do if they have one (check). Task 1.
4. Focus visibility on quiz buttons in both themes (keyboard use at the desk). Checked with the Task 2 screenshots.
