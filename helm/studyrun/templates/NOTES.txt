No Ingress configured. The frontend calls /api on its own host, so the UI
only works once something routes /api to the backend service (port 8080)
and everything else to the frontend service (port 80). For a quick look:
  kubectl port-forward svc/{{ include "studyrun.fullname" . }}-frontend 8080:80
  kubectl port-forward svc/{{ include "studyrun.fullname" . }}-backend 8081:8080
The first serves the UI shell on http://localhost:8080, the second the API
on http://localhost:8081/api (for example /api/health).
